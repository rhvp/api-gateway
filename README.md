## Description

API Gateway and Authentication Service

## Installation

```bash
# install app dependencies
$ npm install
```

## MIGRATION && SEEDING

```
npm run db:migrate

npm run db:seed
```

## Running the app

```bash
# start app
$ npm run start

# watch mode
$ npm run start:dev
```

## Test

```bash
# unit tests
$ npm run test\
```
